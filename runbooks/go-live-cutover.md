# Go-live cutover — romelegion.org

The website and CRM are **already deployed and verified** on the VPS
(165.227.26.223). This runbook is the last mile: point DNS here, flip the
pieces that had to wait for DNS, verify, clean up.

Written so it works for **whoever turns out to own the GoDaddy login**
(the domain is registered at GoDaddy — nameservers `ns57/ns58.domaincontrol.com`).
Current A record points at the old Legionsites host `72.167.249.190` — that IP
is also the rollback target.

Pre-cutover previews (delete in step 5):
- Website: https://legion-preview.howarth.tech/
- CRM admin: https://legion-admin-preview.howarth.tech/

---

## Step 1 — Install the production Caddy blocks (droplet, ~2 min)

Deliberately not installed earlier: Caddy would have retried Let's Encrypt
issuance for a domain that still pointed elsewhere. Run right before (or right
after) the DNS change:

```bash
ssh osh-vps 'sudo bash -s' <<'EOF'
set -e
# Site block — source of truth is caddy/sites/romelegion.org.caddy in the repo
curl -fsS https://raw.githubusercontent.com/howarthTech/legion-rome/main/caddy/sites/romelegion.org.caddy \
  -o /etc/caddy/sites/romelegion.org.caddy
# Admin block — generated by the provisioner
cp /srv/builds/legion-post-platform/out/post-5/caddy/admin.romelegion.org.caddy \
  /etc/caddy/sites/admin.romelegion.org.caddy
caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy
EOF
```

## Step 2 — GoDaddy DNS changes (~5 min, propagates in minutes–hours)

Log in at godaddy.com → My Products → **romelegion.org** → DNS → Manage DNS.

| Action | Type | Name | Value | TTL |
|---|---|---|---|---|
| **Edit** existing | A | `@` | `165.227.26.223` | 600 (½ hour ok too) |
| **Add** | A | `admin` | `165.227.26.223` | 600 |
| Keep | CNAME | `www` | `@` (or edit to point at `romelegion.org`) | — |
| **Delete** | any Legionsites-specific records (forwarding rules, parked A records) | | | |

Don't touch MX/TXT records if the post has email on the domain.

## Step 3 — Verify (~10 min after DNS saves)

```bash
dig +short romelegion.org          # → 165.227.26.223
dig +short admin.romelegion.org    # → 165.227.26.223
curl -sSI https://romelegion.org/ | head -3           # 200, valid padlock
curl -sSI https://www.romelegion.org/ | head -3       # 308 → apex
curl -sSI https://romelegion.org/post-history | head -3   # 301 → /about/history/ (old-URL redirect)
curl -sSI https://admin.romelegion.org/login | head -3    # 200
```

Then click around the real site, and run Lighthouse (target ≥95).

## Step 4 — Flip the DNS-dependent settings (droplet, ~5 min)

```bash
ssh osh-vps 'sudo bash -s' <<'EOF'
set -e
# CRM: events feed moves from the preview URL to the real one
sed -i 's|^EVENTS_FEED_URL=.*|EVENTS_FEED_URL=https://romelegion.org/events/events.json|' /srv/secrets/crm-post-5.env
cd /srv/apps/crm-post-5 && docker compose up -d --force-recreate
EOF
```

- **Twilio** (once wired): Console → phone number → Messaging webhook →
  `https://admin.romelegion.org/webhooks/twilio` (POST).
- **Forms/Resend**: add Resend's DKIM/SPF records for `romelegion.org` in
  GoDaddy (from the Resend dashboard), wait for "Verified", then put the key in
  `/srv/secrets/romelegion.org.env` (`RESEND_API_KEY=...`, mode 600) and test
  both forms end-to-end. Until then the site is live with forms pending — the
  contact page still shows phone/email.
- **Deploy workflow**: restore the public smoke test in
  `.github/workflows/deploy.yml` (curl `https://romelegion.org/` and grep the
  title — see git history of that file).

## Step 5 — Clean up previews (droplet)

```bash
ssh osh-vps 'sudo bash -s' <<'EOF'
rm -f /etc/caddy/sites/legion-preview.howarth.tech.caddy \
      /etc/caddy/sites/legion-admin-preview.howarth.tech.caddy
caddy validate --config /etc/caddy/Caddyfile && systemctl reload caddy
EOF
# Then delete the two DO DNS records (legion-preview, legion-admin-preview)
# from the howarth.tech zone.
```

## Step 6 — Hand off + decommission Legionsites

- CRM admin credentials are at `/srv/secrets/crm-post-5-admin-password.txt`
  on the droplet (root-only). Hand to the post out-of-band; have them change
  the password mindset accordingly (single admin user).
- Keep the Legionsites subscription until romelegion.org has run clean for a
  couple of weeks (it's also the rollback host), then cancel.
  `site-inventory.md` already captured the old site's content.

## Rollback

GoDaddy → DNS → edit A `@` back to `72.167.249.190`. Old site returns as DNS
propagates. Nothing on the droplet needs to change.
