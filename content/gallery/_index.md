This gallery is ready for content but currently empty. To add an album:

1. Create a folder under `content/gallery/`, e.g. `content/gallery/memorial-day-2026/`
2. Drop the photos into that folder (JPG/PNG; Hugo will generate WebP variants automatically)
3. Add an `index.md` inside with the album's title, date, description, and per-photo captions

See the README for a full example, or ask in the repo if you'd like the template scaffolded.
